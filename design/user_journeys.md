# User Journeys

Owner: UX/UI Designers

## J1. Parent, first run (≈ 3 minutes)
1. Welcome → "What this app is, and is not" + disclaimer D-001 (REQ-M8-04).
2. Adult check (the same challenge as the parental gate) → consent screen: what is stored (on this phone only), what is never stored, and how to delete (REQ-PRV-01, REQ-PRV-03).
3. Child profile: nickname, age band, how your child communicates. (No diagnosis field.)
4. Pick 1–3 goals from templates, or "later" (REQ-M6-01).
5. Today screen with the first suggested 10-minute session (REQ-AI-01).
**Pain points addressed:** a tired parent can skip goals; nothing plays any sound during onboarding.

## J2. Parent, daily session (10–15 minutes)
Today → "Start session" → cue card 1 (activity steps, "Pause and wait") → optional "Play example" (tap) → Next… → end → 30-second log (together? which activities? engagement 0–3) (REQ-M2-01…03).

## J3. Child, Child Mode play (caregiver nearby)
Parent taps "Child Mode" → first time only: headphone notice (REQ-SAF-10) → Child home: 6 big picture cards (Drum, Shaker, Songs, Calm, My day, Countdown) + Stop bar. The child taps the drum card → drum pad (sound only on the child's own taps; fade-in; ceiling). The child presses Stop → silence and a "Quiet now" card with a big "Back" picture.
Exit: hold "Grown-ups" 2 s → adult challenge → Parent Mode (REQ-SAF-08).

## J4. Parent, sound sensitivity (1–2 weeks)
Sound toolkit → "Start a sound diary" → quick add (sound picture, place, loudness 1–3, reaction 0–4) in under 30 s → after ≥ 7 entries, "See patterns" (REQ-M5-01, REQ-M5-02) → the toolkit suggests strategies: countdowns, ear defenders situationally, and a referral prompt (REQ-M5-06, REQ-M5-07).

## J5. Parent + child, graded exposure (weeks)
Toolkit → Graded practice → pick a sound → read the rules → "I'm with my child" checkbox (REQ-M5-05) → play at the start level during a favourite activity → distress check-in (0–4) → if 0–1: "Try one small step louder next time?" (at most one step per session) → if the child presses Stop or distress is ≥ 3: silence, the next session starts 2 steps lower, and after 2 stops in a row a 24 h lock with OT or audiologist advice (REQ-SAF-06).

## J6. Parent, 8–12 week review
Goals → Review → the auto summary with raw counts (REQ-M6-03) → edit the text → Export or print (REQ-M6-04). Includes the disclaimer.

## J7. Parent, "Is this therapy proven?"
Learn → Red-flag checker → answer 7 yes / no / not sure questions → verdict with tier and the relevant Education Hub pages (REQ-M8-02, REQ-M8-03).

## J8. Parent asks the coach
Coach → question → answer with citations, or refusal with a clinician pointer, or crisis escalation (REQ-AI-02…05).

## J9. Therapist (LATER, REQ-M9-02)
Portal login (MFA) → caregiver shares a review code → the therapist assigns activities → the caregiver sees the assigned activities on Today.

## J10. Allied professional (MVP)
The caregiver exports the review and shares it by their own chosen channel. There is no in-app access.
